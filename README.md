# Portfolio — Alla Kulykova

UX/UI designer portfolio. React 18 + Vite 5 + TypeScript, plain CSS. Deployed on Vercel from `main` (auto-deploy).

- Desktop (≥ 700 px): five 1440 px stages (Home, About, Projects, Skills, Contact) scaled to the window, with index tabs tucked behind each sheet.
- Mobile (< 700 px): separate layout built from the Figma "Home — Mobile" frame.
- Languages: EN / UA / ES (switch on the first screen, saved in the browser).
- CVs (EN, ES) are downloadable from the Contact section (`public/cv/`).
- Design source: Figma file `kSgkd0V2G25iTcmoXi2HdR`.
- Project plan: [`docs/plan.html`](docs/plan.html).

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build into dist/
```
